# Monos كبلوجنز

كل ميزة في Monos بلوجن مستقل، يعني package لوحده تقدر تقفله أو تفتحه من غير ما تلمس الباقي. التطبيق بيحمّل البلوجنز دي من `~/.dsh/profiles/desktop`، و`scripts/install-desktop.sh` هو اللي بيركّبها وبيتأكد إنها اتركّبت صح.

## البلوجنز

| البلوجن | بيعمل إيه | واجهة؟ | بيعتمد على |
|---|---|---|---|
| `monos-core` | سيرفر MCP (`egx-mcp`، فيه أدوات السجل)، و`/egx/api/*`، وتحديث الأسعار كل 5 دقايق | لأ | — |
| `monos-analyst` | شخصية «Monos» (مساعد السجل)، وبيخليها الافتراضية لأي جلسة جديدة | لأ | `monos-core` (الأدوات) |
| `monos-identity` | شعار Monos في المحادثة الفاضية | أيوه | — |
| `monos-portfolio` | «السجل» (`docs/تحول.md`)، وخانة «Monos» في الشريط الجانبي | أيوه | `monos-core` |

كل بلوجن ليه `FEATURE.md` بيشرح: هيعمل إيه، وشكله، وهيتصرف إزاي، وإزاي تصلّحه لو باظ.

## القواعد
1. **الحساب في Python بس.** أي رقم أو قاعدة، زي القيمة والتكلفة والنمو والسعر الحالي، بيتحسب في `mcp/egx_mcp/`، وبيوصل للشاشات عن طريق `commands.py` → `egx-cli` → `/egx/api`. البلوجن بيعرض بس.
2. **البلوجن ما يعتمدش على بلوجن تاني غير `monos-core`.** الكود المشترك مكانه `plugins/shared/`، وكل بلوجن بيبني نسخته منه جوه `client.js`.
3. **الحالة اللي لازم تبقى واحدة على مستوى الصفحة** بتتعمل بـ `pageShared(key, create)` (`shared/runtime.js`). مثال: مخزن السجل اللي خانة الشريط والشاشة بيقروا منه. ما تستخدمش متغير عادي على مستوى الملف، لأنه هيبقى نسخة منفصلة جوه كل بلوجن.
4. **الـ factory id = اسم الـ package،** و`plugins/build.mjs` بيظبطه أوتوماتيك. React بيجي من التطبيق، وما ينفعش تستورد أي package تاني من التطبيق.
5. **الألوان من `--dsw-alias-*` بس،** وكل رقم جوه `<span class="num">`. والكلام وصف للأرقام، مش توصية. شعارات الشركات في `shared/logos/` هي الاستثناء الوحيد، لأنها علامات الشركات نفسها.

## دورة حياة ميزة جديدة
1. **تجهيز:**
   ```bash
   npm run new-plugin -- <name> "<العنوان بالعربي>"
   ```
   ده بيعمل `plugins/monos-<name>/`، فيه الـ manifest، وصف التسجيل، وخانة في الشريط الجانبي، وصفحة «قيد البناء»، و`FEATURE.md` من القالب.
2. **التعريف:** املا `FEATURE.md` الأول (هتعمل إيه، وشكلها، وهتتصرف إزاي، والبيانات، والاختبارات، ولو باظت)، ونتفق عليه.
3. **البناء:** لو فيه حساب أو بيانات جديدة، بيتضافوا في Python (`commands.py` + اختبار). وبعدها الشاشة في `src/`.
4. **التحقق:** `npm run check`. ده بيعمل:
   - build:check
   - lint
   - اختبارات JS، ومنها عرض كل البلوجنز، وكل بلوجن لوحده، والأداة اللي بتجهّز البلوجن الجديد
   - اختبارات Python
   - ruff
5. **التركيب:** تقفل التطبيق، وبعدين `./scripts/install-desktop.sh --plugins-only`، وبعدين تفتحه وتبص عليه في الوضعين الفاتح والداكن.

## تقفل بلوجن أو ترجّعه
ضيف الصف ده في `~/.dsh/profiles/desktop/cordis.patch.yml`، وبعدين أعد تشغيل التطبيق:
```yaml
- id: monos-portfolio
  disabled: true
```
امسح الصف عشان البلوجن يرجع. ما تقفلش `monos-core`، لأن كل حاجة بتعتمد عليه.

## الأوامر
| الأمر | بيعمل إيه |
|---|---|
| `npm install` | أدوات التطوير (مرة واحدة) |
| `npm run build` | `client.js` لكل بلوجن ليه شاشة |
| `npm run check` | كل الفحوص |
| `npm run fixtures` | يولّد بيانات الاختبار الصناعية من جديد، لو شكل الـ API اتغيّر |
| `npm run new-plugin -- <name> "<title>"` | بلوجن جديد |
| `./scripts/install-desktop.sh [--plugins-only]` | يركّب البلوجنز ويتأكد من التكوين |
