## 2. فحص المصدر الإلكتروني للدين (ق2 + ق1 + ق5)

**فحص ق2 (±15% مع StockAnalysis):** نشر StockAnalysis (صفحة الميزانية الربعية، آخر تحديث 19/10/2026) إجمالي دين 73,812 وصافي دين -5,829. الجدول الداخلي فيه: قصير الأجل 1,662 + "الجزء المتداول من الدين طويل الأجل" 13,830 + إيجارات متداولة 19,427 + دين طويل الأجل 13,814 + إيجارات غير متداولة 25,079.

**التفسير:** بند "الجزء المتداول من الدين طويل الأجل" 13,830 ≈ الدين غير المتداول 13,814، أي إن الموقع عدّ القروض غير المتداولة مرتين. وإذا صححنا ذلك بإضافة القروض المتداولة الفعلية (1,018) بدل الخطأ:
73,812 − 13,830 + 1,018 = **60,999.9**، ومطابق لحسابنا (**60,999.5**) بفرق صفري تقريبًا.

**النتيجة:** الدين يطابق بعد التصحيح. صافي الموقع يختلف لأن الموقع عدّ الدين مرتين. الفحص نجح بعد التفسير، وأوضحت سبب الفرق.

**التعارض مع رقم الشركة:** الشركة قالت في [Q1] ص2 إن صافي النقدية 71.9 مليار جنيه في 31/3/2026، وفي [ER25] ص2 إنها 62.1 مليار في 31/12/2025. هذه الأرقام تستثني أوراق دفع SLB. عند إدخالها يصبح صافي الموقع:
