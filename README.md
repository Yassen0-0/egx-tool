<h1 align="center">Monos</h1>

<p align="center">دفتر واحد لكل اللي حيلتك، محسوب بالجنيه.</p>

---

Monos تطبيق ماك بتسجّل فيه أصولك بنفسك: الدولار اللي محوّشه، والدهب، والبتكوين، وأسهم البورصة المصرية، والصناديق، وشهادات البنك. بيوريك قيمتها النهارده بالجنيه، وزادت قد إيه عن اللي دفعته.

مفيش ربط بأي بنك أو شركة سمسرة. اللي بتكتبه هو اللي بيتحسب. والتطبيق بيوصف الأرقام بس، ومش بيقولك تشتري أو تبيع.

## الشاشة

شاشة واحدة اسمها «السجل»:

- فوق: إجمالي اللي معاك بالجنيه، وتحته نفس المبلغ بالدولار، والتكلفة، والنمو، وحركة النهارده.
- رسم صغير بيبيّن الإجمالي اتغيّر إزاي يوم بيوم (بيظهر بعد يومين تسجيل).
- خانة بحث: تكتب «دولار» أو «دهب» أو «COMI» أو اسم صندوق، وتختار، وتكتب الكمية وسعر الشرا.
- الأصول متقسمة: عملات (ومعاها الدهب)، بتكوين، أسهم، صناديق، شهادات وودائع. كل أصل في سطر واحد بشعاره وقيمته ونموه، ولو دوست عليه بتشوف كل مرة اشتريت فيها وتقدر تعدّل أو تمسح.
- زرار عين يخفي كل الأرقام لو بتشارك الشاشة، وزرار يصدّر السجل لملف CSV يتفتح في Excel.
- لو حوّلت فلوس من أصل لأصل (١٠٠٠ جنيه ← ٢٠ دولار، أو دولار ← صندوق)، أو صرفت منها، بتسجّلها من الأصل نفسه («تحويل منه» أو «خروج»). كل أصل بيوريك حركاته بالترتيب: جت منين، وراحت فين، والرصيد بعد كل حركة، والربح اللي اتحقق. التفاصيل في `docs/الحركات.md`.

وفي المحادثة فيه مساعد اسمه Monos. تقدر تسأله «ثروتي كام؟» أو تقوله «سجّل ٥٠٠ دولار اشتريتهم امبارح بـ ٤٨.٥»، وهو هيأكد معاك قبل ما يكتب أي حاجة.

## الأسعار

بتيجي من EODHD بالخطة المجانية (٢٠ طلب في اليوم)، والتطبيق بيطلب بس اللي إنت شايله:

| الأصل | السعر |
|---|---|
| الدولار | سعره قصاد الجنيه |
| اليورو والإسترليني | عن طريق الدولار |
| الريال والدرهم | من الدولار بسعر الربط الرسمي |
| الدهب | سعر الأونصة العالمي × الدولار. جرام أي عيار (٢٤، ٢٢، ٢١، ١٨، ١٤) بنسبة الدهب الصافي اللي فيه، والجنيه الدهب ٨ جرام عيار ٢١. المصنعية مش داخلة في القيمة |
| البتكوين | سعره بالدولار × الدولار |
| أسهم البورصة المصرية | إغلاق آخر جلسة، بعد الساعة ٤ العصر |
| صناديق S&P 500 الأمريكية (SPY وIVV وVOO) | إغلاق آخر جلسة في نيويورك بالدولار × الدولار |
| الصناديق التانية وأي حاجة تانية | السعر اللي بتكتبه إنت |
| الشهادات | من شروطها: المبلغ، وفوقه العائد المتراكم لو العائد بيتصرف في الآخر |

التكلفة بتتحسب بالجنيه اللي دفعته فعلًا يوم الشرا، فلو الدولار غلي بعد كده النمو بيبان.

## التثبيت

على الماك ده:

1. لازم يكون `Monos.app` موجود في Applications. لو مش موجود: `./scripts/rebrand-desktop.sh`.
2. افتح التطبيق مرة واقفله.
3. شغّل `./scripts/install-desktop.sh`، وبعدين افتح التطبيق.

السكربت بيكتب مكان المشروع في `~/.dsh/.env`، وبيربط البلوجنز بالتطبيق. أي تعديل في المشروع بيبان بعد ما تقفل التطبيق وتفتحه.

على ماك تاني: فيه حزمة جاهزة (`Monos-Installer`) فيها التطبيق والمشروع وسكربت بيعمل كل الخطوات، وبيسألك على المفاتيح. التفاصيل في `اقرأني.txt` جواها.

المفاتيح بتتحط في `~/.dsh/.env`:

```
EODHD_API_KEY=...
GOOGLE_API_KEY=...
```

الأول للأسعار، والتاني لموديل Gemini اللي المساعد شغّال بيه. مفيش مفتاح بيتكتب في أي ملف جوه المشروع.

## التحديثات

التطبيق مش بياخد تحديثات من برّه، إحنا بس اللي بنحدّثه. لما يكون فيه تحديث:

```bash
git pull
./scripts/install-desktop.sh --plugins-only
```

والتطبيق مقفول، وبعدين افتحه.

## بياناتك

- السجل كله في `data/egx.sqlite`، على جهازك بس، ومش بيترفع على GitHub.
- قبل أي تغيير في شكل القاعدة بتتعمل نسخة احتياطية لوحدها في `data/backups/`.
- إجازات البورصة في `data/manual/holidays.csv`. أيام الإجازة مش بتتطلب فيها أسعار أسهم.

## للتطوير

المشروع ٤ بلوجنز بتتركّب جوه التطبيق، والحساب كله في Python:

| الفولدر | فيه إيه |
|---|---|
| `mcp/egx_mcp/` | حساب السجل، والفهرس، والأسعار، والتخزين، وأدوات المساعد |
| `plugins/monos-portfolio/` | شاشة «السجل» وخانة Monos في الشريط الجانبي |
| `plugins/monos-core/` | سيرفر الأدوات، ومسارات `/egx/api`، وتحديث الأسعار كل ٥ دقايق |
| `plugins/monos-analyst/` | شخصية المساعد |
| `plugins/monos-identity/` | الأيقونة في المحادثة الفاضية |
| `plugins/shared/` | الكود المشترك وشعارات الشركات |

أول مرة: `npm install`. وبعد أي تعديل:

```bash
npm run build    # بعد تعديل الشاشة
npm run check    # كل الاختبارات
```

قواعد الشغل في `CLAUDE.md`، وتفاصيل البلوجنز في `docs/PLUGINS.md`، واتفاق التحول في `docs/تحول.md`.

## من جوه

Monos مبني على المحرك مفتوح المصدر DeepSeek Harness (رخصة MIT، وإشعار الرخصة لازم يفضل موجود). التطبيق نفسه ما بيعرضش اسمه ولا شعاره:

- `scripts/rebrand-desktop.sh` بيبني `Monos.app`: الأيقونة والاسم، وقفل التحديث التلقائي، وإعادة التوقيع، وطبقة الإعدادات.
- `scripts/asar-brand.py` بيغيّر نصوص الواجهة جوه التطبيق.
- `scripts/strip-deepseek-profile.py` بيقفل حساب DeepSeek ومزوّديه والتتبّع.

بعض الأسماء الداخلية فضلت زي ما هي لأن تغييرها بيكسر التطبيق: `~/.dsh`، `@deepseek-ai/*`، `com.deepseek.dsh`، `dsh://`، `--dsw-alias-*`.
