# monos-core: الأساس

## هتعمل إيه
ده البلوجن الوحيد اللي فيه **حسابات وبيانات**، وكل البلوجنز التانية بتعتمد عليه. فيه حاجتين:
1. **صف `egx-mcp`:** بيشغّل سيرفر MCP (`mcp/egx_mcp/server.py`). ده فيه الـ 32 أداة اللي المحلل بيستخدمها، زي التقييم والمخاطر والتخزين والمحفظة والسوق.
2. **صف `monos-core`:** ده `host/api.mjs`، وفيه حاجتين:
   - مسارات `/egx/api/*` اللي الشاشات بتقرا منها. كل مسار بيشغّل `egx-cli`، اللي هو `mcp/egx_mcp/commands.py`، يعني نفس الكود اللي أدوات MCP بتستخدمه.
   - تحديث الأسعار من EODHD كل 5 دقايق.

## هتتصرف إزاي
- **الأمان:**
  - بيقبل طلبات من `127.0.0.1` و`localhost` بس.
  - أي طلب بيعدّل حاجة لازم يكون JSON object، ومعاه هيدر `x-egx-request`، ومن نفس الـ Origin.
  - لو جسم الطلب غلط بيرجّع 400، ولو حصل أي خطأ بيرجّع 500. مافيش طلب بيفضل معلّق.
- **تحديث واحد في نفس الوقت:** بيحترم الرصيد اليومي لـ EODHD. التحديث التلقائي بيغطي المحفظة، وبعدها «متابعتي» بس. باقي الأسهم بتتحدّث بس لما تطلبها، من `POST /egx/api/market/<SYM>/sync`، وده بيستهلك تحديث واحد. والطلب ده مش بيشتغل في نفس وقت التحديث التلقائي. وفي الإجازات المسجلة في `data/manual/holidays.csv` ما بيعملش تحديث.
- **قاعدة البيانات:** `data/egx.sqlite`. شكلها مرقّم، وقبل أي ترقية بتتعمل نسخة احتياطية في `data/backups/`.

## الإعداد
القيم دي في `~/.dsh/.env`، و`install-desktop.sh` بيكتبهم: `EGX_HOME` و`EGX_DATA_DIR` و`EGX_UV`. ومفتاح EODHD بيتحط في `EODHD_API_KEY` أو في `egx-api.docx`.

## الاختبارات
- Python: `uv run --project mcp pytest -q`، وده 103 اختبار.
- `plugins/test/host-routes.test.mjs`: كل مسار، والأمان.

## لو باظت
**ما تقفلوش.** من غيره كل الشاشات هتقول «تعذّر التحميل»، والمحلل هيفقد أدواته.

اختبره من الطرفية:
```bash
uv run --project mcp egx-cli market-summary
```
وكمان:
```bash
uv run --project mcp egx-cli validate-data
```
