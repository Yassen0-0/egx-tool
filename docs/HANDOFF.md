# Monos — تقرير التسليم للمطوّر القادم

> اقرا الملف ده قبل أي تعديل. الاتفاق الكامل في `docs/تحول.md`، وقواعد الشغل في `CLAUDE.md`.
> آخر تحديث: 20 أكتوبر 2026.

## 1. المشروع إيه
**«السجل»:** دفتر شخصي لأصول المستخدم بالجنيه المصري. بيضم عملات، ودهب، وبتكوين، وأسهم البورصة المصرية، وصناديق، وأي أصل تاني بيتضاف بالاسم. المستخدم بيكتبها بنفسه، ومفيش ربط بوسيط.

بيشتغل جوه تطبيق **Monos** على الماك. **وصف للأرقام، وممنوع أي توصية شرا أو بيع.**

أداة تقييم أسهم EGX30 اللي كانت قبله اتشالت يوم 20/10/2026. كودها في تاريخ git، وجداولها (`valuations`، و`change_log`، و`watchlist`) لسه في قاعدة المستخدم.

## 2. القرارات الثابتة
| القرار | التفاصيل |
|---|---|
| التكلفة | بالجنيه اللي اتدفع فعلًا وقت الشرا، وبتتحفظ مع سعر التحويل (`fx_egp`). تغيّر الدولار بعد كده ما بيغيرهاش |
| القيمة | الكمية × آخر سعر معروف بالجنيه، والسعر معاه تاريخه. الأصل اللي ملوش سعر برّه الإجمالي |
| النمو | (القيمة − التكلفة) ÷ التكلفة، على الأصول اللي ليها سعر بس |
| اليوم | حركة أسعار السوق الحديثة بس. السعر اليدوي ما بيدخلش «اليوم» |
| الصناديق | المكونات للعرض بس، ومش بتتجمع |
| الدهب | جوه «عملات»، بالجرام أو الأونصة، وبيتحسب دهب خالص |
| الدفع | مفيش اشتراكات: خطة EODHD المجانية |

## 3. البنية
```
mcp/egx_mcp/
  catalog/            الفهرس: العملات، والدهب، والبتكوين، وEGX30 بعملة كل سهم، وfunds.json، وأصول المستخدم
  store/db.py         الجداول والترقيات المرقّمة (نسخة احتياطية قبل كل ترقية)
  store/portfolio.py  حساب السجل: الإضافة والتعديل والحذف، والأسعار اليدوية، ومكونات الصناديق، والملخص
  market/             EODHD، وتقويم البورصة، والأسعار (prices.py)، والتحديث (sync.py)
  commands.py         كل عملية مكتوبة مرة واحدة: egx-cli للشاشة، وأدوات MCP للمساعد
plugins/
  monos-core/         صف MCP، و/egx/api، والتحديث كل 5 دقايق
  monos-analyst/      شخصية «Monos» (مساعد السجل)
  monos-identity/     شعار المحادثة الفاضية
  monos-portfolio/    شاشة «السجل»، وخانة Monos في الشريط
  shared/             runtime، وformat، وidentity، والشعارات (logos/ وlogo.js)
```

**تدفق البيانات:**
- **الشاشة:** `/egx/api/*`، وبعدها `egx-cli`، وبعدها `commands.py`، وبعدها SQLite.
- **المساعد:** أدوات MCP، وبعدها نفس الدوال.

## 4. حاجات ممكن تفاجئك
- **سعر شمعة النهارده:** EODHD بيرجّع شمعة لليوم وهو لسه شغال، في الفوركس والكريبتو. علشان كده المزامنة بتجيب آخر يوم متخزن تاني، مرة واحدة في اليوم.
- **اليورو والإسترليني:** بيتحسبوا عن طريق الدولار (EURUSD × USDEGP)، لأن سعرهم المباشر مقابل الجنيه بيتنطط.
- **`VLMR`:** بالدولار (مصر الكويت القابضة سابقًا).
- **لو بلوجن اتمسح:** لازم `./scripts/install-desktop.sh --plugins-only` والتطبيق مقفول. السكربت بيشيله من البروفايل.
- **الشاشة بتحمّل الفهرس مرة واحدة** وبتفلتر عليه. السبب إن نداء `egx-cli` بياخد حوالي 0.35 ثانية.
