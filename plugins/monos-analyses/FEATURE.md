# monos-analyses: التحليلات

> **مقفولة من يوم «السجل» (`docs/تحول.md`)**: صفها في `cordis.patch.yml` عليه `disabled: true`، والكود هيتمسح في مرحلة الحذف.

## هتعمل إيه
فيها كل التقييمات المحفوظة، الكاملة والخفيفة، متجمّعة حسب السهم. ولكل تقييم صفحة كاملة فيها:
- التقرير
- الطرق والافتراضات
- الفحوصات
- المخاطر
- المصادر
- ملاحظات الناقد
- سبب أي تغيير في السعر العادل

## شكلها
- الشريط الجانبي فيه خانة «التحليلات».
- القائمة (`AnalysesList`):
  - فلترة بالسهم والتصنيف والنوع والفترة.
  - كل سهم بيظهر بآخر تقييم له، وتحته النسخ الأقدم بلون أهدى.
  - الأسهم اللي تحت سعر الحماية بتطلع الأول.
- صفحة التحليل (`AnalysisDetail`):
  - رقم النسخة.
  - ملخص ومسطرة كبيرة (`BigRuler` من `shared/components.js`).
  - شارت السعر العادل مقابل السعر (`FairHistoryChart`).
  - أقسام بتنقّل جوه الصفحة (`SECTIONS`).

## هتتصرف إزاي
- الأرشيف بيتحمّل كله، صفحة ورا صفحة (200 في كل مرة، B9)، فترقيم النسخ بيفضل صح مهما كان العدد.
- كارت «تحت سعر الحماية، يحتاج مراجعة» بيظهر لآخر نسخة بس (B8).
- فلترة التاريخ بأيام القاهرة (B16).
- لما تجيلها من شاشة السوق، بتفتح التحليل والقسم المطلوب مباشرة (`nav.pendingAnalysisId`).

## البيانات
بتقرا بس، من `monos-core`:
- `GET /egx/api/valuations?kind=&limit=200&offset=N`
- `/valuations/<id>`
- `/valuations/series/<SYM>`
- `/market`
- `/market/<SYM>/history`

مافيش أي طلب كتابة. التقييمات بيحفظها المحلل من المحادثة.

## الاختبارات
- `render.test.mjs`
- `format.test.mjs`، ومعاه `labels.mjs`: التسميات العربية، ومافيهاش أي كلمة توصية.
- `mcp/tests/test_store.py`: قواعد الحفظ.

## لو باظت
- **تقفلها لوحدها:** `- id: monos-analyses` ومعاه `disabled: true` في ملف إعدادات التطبيق.
- **أمر للفحص:** `uv run --project mcp egx-cli valuations-list '{"kind": ""}'`.
- **بعد أي تعديل:** `npm run build`، وبعدين `npm run check`، وبعدين أعد تشغيل التطبيق.
