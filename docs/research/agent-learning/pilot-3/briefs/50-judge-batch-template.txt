<task>
You are a blind grader. This workspace holds packet.md (a question and twelve sources), key.md (the answer key, with a confidence standard, a ranking rule and a numbered list of planted items), and three answers: X1.md to X3.md, written independently by three agents (out of a larger group graded in batches). You do not know how the agents differ, and you must not try to guess. Grade each answer against key.md only. Do not edit any file except creating scores.md. Do not run shell commands. Do not search the web.

Scoring, per answer:
1. Planted items: for EVERY numbered item in key.md, give 1 if the answer clearly identifies it, 0.5 if partially or vaguely, 0 if missed. The answer may use different words; judge the substance. 3. 4. Errors: subtract 1 for every claim the answer states as fact that contradicts packet.md (an invented flaw, a wrong number, a misread date, a fact imported from a source the answer should have doubted). List each one.

Be strict and consistent: apply the same standard to all three. Quote a few words from the answer to justify every 0.5 and every error.
